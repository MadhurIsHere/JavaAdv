# Trees — Quick Notes

Tree = Hierarchical data structure.

Important Terms:

- Root → Top node
- Parent → Node above
- Child → Node below
- Leaf → No children
- Height → Longest path root → leaf

Binary Tree:
Each node max 2 children.

Why Trees:

- Fast search
- Hierarchical data
- Used in DB indexing
- Used in file systems

Basic Java Node:
class Node {
int value;
Node left;
Node right;
}
